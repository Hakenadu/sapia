# @sapia/plugin-mermaid

Mermaid language support for [Sapia](https://github.com/Hakenadu/sapia): detection, highlighting, completion, validation, rendering and metamodel converters.

```bash
npm install @sapia/plugin-mermaid @sapia/core
```

The plugin is part of Sapia Web and Sapia Desktop already. The package is for building your own Sapia distribution or reusing the Mermaid support in other tools.
